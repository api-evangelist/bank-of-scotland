# Bank of Scotland

> Bank of Scotland is a UK high-street retail and commercial bank (founded 1695, Edinburgh), a wholly owned brand of Lloyds Banking Group. As one of the CMA9 mandated account providers it publishes UK Open Banking APIs: a PUBLIC unauthenticated OBIE Open Data reference API (ATMs, branches, products) and the FAPI-secured OBIE Read/Write family - Account & Transaction Information (AIS), Payment Initiation (PIS) and Confirmation of Funds (CBPII) - accessed via the Lloyds Banking Group developer platform after eIDAS/OBIE certificate onboarding.

## APIs

- [Open Data API](https://developer.lloydsbanking.com/open-data): Public, unauthenticated ATM/branch/product reference data. Live at https://api.bankofscotland.co.uk/open-banking/v2.2
- [Account & Transaction Information API (AIS)](https://developer.lloydsbanking.com/): Read accounts, balances, transactions, standing orders, direct debits, beneficiaries, statements, parties, products. FAPI-secured.
- [Payment Initiation API (PIS)](https://developer.lloydsbanking.com/): Domestic, scheduled, standing-order, international and file payment consents and orders. FAPI-secured, idempotent.
- [Confirmation of Funds API (CBPII)](https://developer.lloydsbanking.com/): Card-based payment instrument issuers confirm funds availability. FAPI-secured.
